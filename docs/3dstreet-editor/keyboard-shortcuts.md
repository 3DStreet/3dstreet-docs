# Keyboard Shortcuts

* `t` or `w` - Translate
* `e` - Rotate
* `l` or `s` - Scale
* `r` - Shape Tool (measure and draw)
* `h` - Hand
* `o` - Toggle transform axes between object and world space
* `c` or `d` - Duplicate selected entity
* `f` - Focus on selected entity
* `g` - Toggle grid visibility
* `p` - Play the scene (when it has something playable)
* `del` | `backspace` - Delete selected entity
* `` ` `` - Toggle panels
* `1` - Perspective view
* `ctrl` | `cmd` + `c` - Copy selected entity
* `ctrl` | `cmd` + `x` - Cut selected entity
* `ctrl` | `cmd` + `v` - Paste entity
* `esc` - Unselect entity
* `ctrl` | `cmd` + `z` - Undo
* `ctrl` | `cmd` + `shift` + `z` - Redo

## While drawing a shape

* `Enter` or double-click - Finish the shape
* `Backspace` - Remove the last point
* `esc` - Finish, dropping the point under the cursor

See [Shape Tool: Measure and Draw](/docs/3dstreet-editor/shape-tool) for details.
